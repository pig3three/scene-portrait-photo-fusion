# Scene Portrait Photo Fusion

上传一张已授权人物照片和一张真实场景照片，将人物自然融合进场景，生成多种姿势的独立人像成片。

## 功能

- 保持人物身份、发型和比例一致
- 匹配场景透视、光线、地面接触、阴影、反光和景深
- 支持 4、8、12 或 16 张独立照片
- 支持保留当前服饰、用户指定换装、半身照自动补全下装与鞋子
- 支持丰富的手部、腿脚、侧身、回望、行走和俯身动作
- 支持近景、中景、远景三种距离模式，并按距离匹配人物比例、清晰度、空气透视和阴影

## 安装与最简调用

```text
请安装 https://github.com/pig3three/scene-portrait-photo-fusion
```

```text
用 $scene-portrait-photo-fusion 融合这两张照片。
图片 1：已授权人物参考照片
图片 2：实际场景照片
生成 8 张竖版 3:4 独立照片，保持身份一致并真实融入场景。
```

## 服饰规则

- 未填写服饰且人物图为全身：保留当前服饰和鞋子。
- 用户填写服饰或鞋子：按描述换装并锁定整组造型。
- 未填写服饰且人物图为半身：保留可见上装，自动搭配一套下装和鞋子。
- 自动补全是 AI 造型设计，不代表人物真实拥有或穿过这些单品。

### 指定服饰

```text
【服饰模式】指定服饰
上装：米白色短款针织开衫
下装：浅卡其色高腰阔腿裤
鞋子：棕色低跟乐福鞋
配饰：不添加首饰和包

保持同一套服饰贯穿全部照片，不改变颜色、材质、裤长和鞋型。
```

也可只替换部分：

```text
保留人物当前上装。
下装改为深蓝色直筒牛仔裤。
鞋子改为白色低帮帆布鞋。
未指定的配饰不要新增。
```

### 半身参考自动补全

```text
【服饰模式】半身自动补全
人物参考图只有半身。
保留可见上装、领口、袖型、材质和颜色。
根据上装风格、人物比例、场景、季节和动作安全性，
自动搭配一套协调的下装和鞋子。

先写明“AI 自动补全”的下装、鞋子、颜色、材质和版型，
锁定后用于所有照片，不得变换款式。
不要添加品牌、Logo、包、帽子或首饰。
```

## 背景一致性与写实增强

新版把场景作为一张固定的“母版背景”，不再让模型为每个姿势重新绘制场景：

- 先锁定原始场景中的文字字形、招牌数量与顺序、门窗、海报、建筑细节、充电宝或支付设备、线缆、灯具和装饰物。
- 如果需要清除汽车、自行车、脚手架等，只在母版背景上清理一次；后续所有照片复用同一张清理后的母版。
- 人物以局部蒙版融合，母版中人物以外的像素原则上保持不变，只允许增加合理的遮挡、反光、接触阴影和投影。
- 照片按顺序逐张生成，每张与母版锚点清单核对通过后才生成下一张。文字缺失、设备移位、线缆变化、门窗数量变化等均会触发重试。
- 写实检查增加皮肤纹理、发丝边缘、手脚结构、衣物受力、眼镜反光、阴影方向、颗粒、锐度、白平衡、景深和镜头特征，避免蜡像皮肤、抠图光边、假虚化、过度 HDR 和人物与背景清晰度不匹配。

精确保留中文文字或小型设备时，应使用原始背景像素的蒙版合成。纯生成式重绘无法保证逐字、逐像素一致，因此本技能会优先保留母版，而不是重绘整个背景。

```text
【统一清理】

【真实摄影要求】

```

## 远景融合真实感升级

新版不再把近景人物简单缩小后放入远处，而是为每张照片先标定地平线、落脚点、同深度参照物和人物画面占比：

- 近景：人物占画面高度 55%–85%，保留可见面部和服装细节。
- 中景：人物占 30%–55%，细节、局部对比度和边缘锐度与同深度物体一致。
- 远景：人物占 12%–30%，通过轮廓、发型、眼镜、脸部大比例、身形和服饰辨认身份，不强行保留毛孔级五官。
- 低于 12% 时，面部身份可靠性有限，优先保持轮廓和服饰一致。

每张照片采用“两阶段融合”：先形成身份、服饰、姿势和机位正确的人物层，再把人物局部合成到固定背景母版中。融合阶段匹配天空光、地面反光、邻近建筑反光、空气透视、颗粒、压缩、景深和运动模糊。

脚底使用三层阴影：鞋底下的窄接触阴影、沿光线方向扩散的柔和投影、裤脚与鞋面及双腿之间的环境遮蔽。远景阴影会更小、更软、更低对比。

```text
用 $scene-portrait-photo-fusion 融合我上传的两张照片。

图片 2：实际场景照片

【输出】

保持脸型、五官比例、年龄感、肤色、发型、发际线、身形、肩宽、
身体比例、眼镜和已有配饰一致。不要美化成另一个人，不要磨皮、
年轻化、改变肤色、拉长四肢或改变身材。

【人物参考充分性】
优先使用：正脸、三分之二侧脸、正面全身、侧面全身、背面或回头照片。
如果只有半身照，请明确标注身高、腿长、背面、下装和鞋履为近似补全。

【服饰模式】

配饰：

【背景母版】
以图片 2 建立唯一背景母版。锁定建筑、屋顶、门窗、墙面文字字形、

需要清除：无／汽车、自行车、行人、脚手架或其他内容
只在母版上清理一次，后续全部复用同一结果。

【距离模式】
每张标注：近景／中景／远景
近景人物高度占比：55%–85%
中景人物高度占比：30%–55%
远景人物高度占比：12%–30%
本组期望分配：近景 __ 张，中景 __ 张，远景 __ 张

禁止将近景人物简单缩小为远景人物。每张先输出：
- 地平线高度
- 双脚落点和地面方向
- 同深度比例参照物
- 人物预计画面高度占比
- 头身比例与前景遮挡
- 投影方向、长度、颜色和软硬度

【两阶段融合】
第一阶段：建立身份、服饰、姿势、身体比例和目标机位正确的人物层。
第二阶段：只在人物、必要遮挡、环境反光和阴影区域进行局部融合，
背景母版其余像素保持不变，不得重新生成整张场景。

【远景细节匹配】
根据人物像素高度，匹配同深度物体的空间分辨率、边缘锐度、微对比度、
饱和度、颗粒、压缩、空气透视、景深和运动模糊。
人物不得比同深度建筑或物体更清晰、更干净或更饱和。
远景不得保留当前像素尺寸无法承载的眼睛、毛孔和服装纹理。

【环境光采样】
在人物站位采样并应用：
- 天空方向、颜色和软硬度
- 地面低角度反光
- 邻近墙体、树木和装饰物的微弱反光
移除人物参考图中与现场冲突的室内光或自拍补光，不得产生彩色描边。

【脚底与阴影】
同时生成：
1. 承重鞋底下狭窄的接触阴影
2. 沿现场光线方向扩散的低对比柔和投影
3. 裤脚与鞋面、双腿之间的环境遮蔽
地面纹理应轻微打断鞋底边缘。远景阴影更小、更软、更弱。

【姿势】
设计 8 个不重复姿势，覆盖正面、三分之二侧身、完整侧身、背面回望、
静态站立、自然行走和转身；覆盖错步、交叉腿、宽站、脚跟抬起、屈膝；
覆盖自然垂手、插袋、整理袖口、轻扶外套、双手背后和安全环境互动。

【逐张审计】

- 人物尺寸是否与同深度参照物匹配，头部是否偏大
- 远景人物是否比同深度背景过度清晰
- 五官细节是否超过目标像素尺寸
- 双脚是否接地，是否有光边或漂浮
- 三层阴影是否符合现场方向和软硬度
- 天空光、地面反光和建筑反光是否作用于人物
- 人物和背景是否像同一焦段、天气和相机拍摄
- 背景文字、建筑、设备和装饰是否发生漂移

任一项失败时，使用背景母版和更小局部蒙版重试；
不得通过重新生成整张背景修复。

最后输出：
1. 人物身份锁定
2. 完整服饰锁定
3. 背景母版与锚点清单
4. 每张距离与透视标定
5. F01–F08 姿势方案
6. 8 张独立照片
7. 每张一致性、距离真实感和摄影真实感审计
```

## 建议

- 人物图最好显示脸部、全身、完整服装和鞋履。
- 远景全身照片最好补充正面、侧面和背面全身参考；只有半身照时，身形补全只能近似。
- 半身补全项必须明确标为 AI styling completion。
- 真人参考图必须获得本人授权。
- 可能被误认为真实事件时，应标注为 AI 生成。
