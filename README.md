# Scene Portrait Photo Fusion

上传一张已授权人物照片和一张真实场景照片，将人物自然融合进场景，生成多种姿势的独立人像成片。

## 功能

- 保持人物身份、发型和比例一致
- 匹配场景透视、光线、地面接触、阴影、反光和景深
- 支持 4、8、12 或 16 张独立照片
- 支持保留当前服饰、用户指定换装、半身照自动补全下装与鞋子
- 支持丰富的手部、腿脚、侧身、回望、行走和俯身动作

## 安装与最简调用

```text
请安装 https://github.com/pig3three/scene-portrait-photo-fusion
```

```text
用 $scene-portrait-photo-fusion 融合这两张照片。
图片 1：已授权人物参考照片
图片 2：实际场景照片
生成 8 张竖版 3:4 独立照片，保持身份一致并真实融入场景。
```

## 服饰规则

- 未填写服饰且人物图为全身：保留当前服饰和鞋子。
- 用户填写服饰或鞋子：按描述换装并锁定整组造型。
- 未填写服饰且人物图为半身：保留可见上装，自动搭配一套下装和鞋子。
- 自动补全是 AI 造型设计，不代表人物真实拥有或穿过这些单品。

### 指定服饰

```text
【服饰模式】指定服饰
上装：米白色短款针织开衫
下装：浅卡其色高腰阔腿裤
鞋子：棕色低跟乐福鞋
配饰：不添加首饰和包

保持同一套服饰贯穿全部照片，不改变颜色、材质、裤长和鞋型。
```

也可只替换部分：

```text
保留人物当前上装。
下装改为深蓝色直筒牛仔裤。
鞋子改为白色低帮帆布鞋。
未指定的配饰不要新增。
```

### 半身参考自动补全

```text
【服饰模式】半身自动补全
人物参考图只有半身。
保留可见上装、领口、袖型、材质和颜色。
根据上装风格、人物比例、场景、季节和动作安全性，
自动搭配一套协调的下装和鞋子。

先写明“AI 自动补全”的下装、鞋子、颜色、材质和版型，
锁定后用于所有照片，不得变换款式。
不要添加品牌、Logo、包、帽子或首饰。
```

## 背景一致性与写实增强

新版把场景作为一张固定的“母版背景”，不再让模型为每个姿势重新绘制场景：

- 先锁定原始场景中的文字字形、招牌数量与顺序、门窗、海报、建筑细节、充电宝或支付设备、线缆、灯具和装饰物。
- 如果需要清除汽车、自行车、脚手架等，只在母版背景上清理一次；后续所有照片复用同一张清理后的母版。
- 人物以局部蒙版融合，母版中人物以外的像素原则上保持不变，只允许增加合理的遮挡、反光、接触阴影和投影。
- 照片按顺序逐张生成，每张与母版锚点清单核对通过后才生成下一张。文字缺失、设备移位、线缆变化、门窗数量变化等均会触发重试。
- 写实检查增加皮肤纹理、发丝边缘、手脚结构、衣物受力、眼镜反光、阴影方向、颗粒、锐度、白平衡、景深和镜头特征，避免蜡像皮肤、抠图光边、假虚化、过度 HDR 和人物与背景清晰度不匹配。

精确保留中文文字或小型设备时，应使用原始背景像素的蒙版合成。纯生成式重绘无法保证逐字、逐像素一致，因此本技能会优先保留母版，而不是重绘整个背景。

### 背景锁定提示词模板

```text
用 $scene-portrait-photo-fusion 融合这两张照片。
图片 1：已授权人物参考照片
图片 2：实际场景照片

生成 8 张竖版 3:4 独立照片。

【背景母版要求】
以图片 2 建立唯一的母版背景，整组照片不得重新绘制背景。
锁定所有可见文字的字形与位置、招牌数量和顺序、门窗、海报、
建筑结构、设备、充电宝、线缆、灯具、装饰物及其相对位置。
不同照片只允许改变人物、合理遮挡、反光和阴影。

【统一清理】
需要清除：自行车、汽车。
只在母版背景上清理一次，所有照片复用同一清理结果。

【真实摄影要求】
保留自然皮肤纹理、发丝、衣物褶皱和普通面部不对称；
匹配背景的锐度、颗粒、白平衡、动态范围、镜头虚化和压缩质感；
不要磨皮、塑料皮肤、过度锐化、过度 HDR、假景深或抠图光边。

先输出背景锚点清单和 F01–F08 方案。
逐张生成并逐张核对；任一文字、设备或建筑锚点漂移都必须重试。
```

## 建议

- 人物图最好显示脸部、全身、完整服装和鞋履。
- 半身补全项必须明确标为 AI styling completion。
- 真人参考图必须获得本人授权。
- 可能被误认为真实事件时，应标注为 AI 生成。
