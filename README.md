# Scene Portrait Photo Fusion

上传一张已授权的人物参考照片和一张真实场景照片，将人物自然融合进场景，生成多种姿势的独立人像成片。

## 功能

- 尽量保持脸部、年龄感、发型、身形、服装和鞋履一致
- 保留场景建筑、透视、光线、材质和空间结构
- 匹配比例、地面接触、阴影、反光、景深、颗粒和色温
- 支持 4、8、12 或 16 张独立照片，默认 8 张
- 支持丰富的手部、腿脚、侧身、转身、回望、行走、俯身和环境互动
- 每张照片独立生成，不用拼贴图代替成片

## 安装

```text
请安装 https://github.com/pig3three/scene-portrait-photo-fusion
```

## 最简调用

```text
用 $scene-portrait-photo-fusion 融合这两张照片。

图片 1：已授权的人物参考照片
图片 2：实际场景照片

生成 8 张竖版 3:4 独立人像照片。
保持人物脸部、发型、身形、服装和鞋履一致，
使比例、透视、光线、阴影和地面接触真实。
每张使用不同的手部、腿脚、身体方向、视线和环境互动。
```

## 完整模板

```text
用 $scene-portrait-photo-fusion 分析并融合这两张照片。

图片 1：已授权的人物参考照片
图片 2：实际拍摄场景照片

【输出】
照片数量：8
画幅：竖版 3:4
风格：自然、松弛、有生命感、真实摄影
形式：8 张独立照片，可附加联系表

【人物锁定】
保持同一张脸、年龄感、肤色、发型、身形比例、服装款式、
材质、颜色、鞋履和配饰。不要美化成另一个人。

【场景与融合】
保持建筑、道路、门窗、植物、位置、透视和光线。
人物比例正确，双脚接触地面；匹配光线、阴影、色温、
反光、景深、清晰度和颗粒；避免悬浮感和贴图感。
不得增加现场不存在的结构或道具。

【动作】
覆盖正面、45 度侧身、纯侧身、背面回望；
站立、错步、交叉腿、宽站、侧点脚尖、抬脚跟、屈膝；
横向行走、向前行走、转身中间态；
张掌、比 V、指心、双手比心、整理头发、整理袖口、
双手背后、轻扶衣摆、指向真实场景元素；
至少一个舒适、安全、不过度的轻微前倾或俯身。

不要重复手部＋腿部＋身体朝向＋视线组合。
先锁定 F01–F08，再逐张生成。
每次同时参考原始人物图和原始场景图。
成片中不要出现编号、说明、边框、Logo 或水印。
```

## 身份优先追加语

```text
身份一致性高于姿势复杂度。
复杂手势或大幅转身若导致脸部漂移，请简化动作，
但必须保持面部结构、年龄感、发型和服装。
```

## 使用建议

- 人物图最好显示脸部、全身、完整服装和鞋履。
- 场景图最好显示地面、纵深、光线和可站立区域。
- 未显示的下装和鞋履不会被当成真实信息；请补图或允许中性补全。
- 真人参考图必须获得本人授权。
- 合成图可能被误认为真实事件时，应明确标注为 AI 生成。
